# DeltaEngine座学 第2講 — 黄色と紫のチャート読解

作成日: 2026-07-21  
対象: 第1講「注文フローと価格反応」を読んだ人  
テーマ: 停滞と逆行を、時間の流れとして読む

---

## この講義のゴール

この講義を読み終えたとき、次のことを説明できれば合格。

1. 黄色と紫が「売買命令」ではない理由
2. 黄色から紫へ変わる過程が何を意味するか
3. 30秒、1分、3分を独立した3票として数えてはいけない理由
4. 同じ現象でも、1分後と10分後で結論が変わる理由
5. 実データを使って、観測事実と解釈を分ける方法

第2講で最も大切な一文はこれ。

> **色を点で見ない。圧力と価格反応が、時間の中でどう変化したかを見る。**

---

## 1. 第1講の復習

### 黄色

黄色は `STALLED`。

明確な積極買いまたは積極売りがあるのに、価格がほとんど進んでいない。

```text
BUY_STALLED  = 買い圧力 + 価格停滞
SELL_STALLED = 売り圧力 + 価格停滞
```

### 紫

紫は `TRAPPED`。

明確な積極買いまたは積極売りがあるのに、価格が圧力と逆方向へ進んでいる。

```text
BUY_TRAPPED  = 買い圧力 + 価格下落
SELL_TRAPPED = 売り圧力 + 価格上昇
```

### 色が答えている質問

黄色と紫が答えるのは、次の質問である。

> 積極注文の方向に対して、価格は素直に反応したか。

色は、その後の価格方向を保証していない。

---

## 2. 色を見る前に確認する4項目

色を見つけたら、すぐに意味を決めない。

次の順序で確認する。

### 1. どこで起きたか

- 直前高値の近くか
- 直前安値の近くか
- 値幅の中央か
- 急騰または急落の直後か
- 横ばいの中か

同じBUY_STALLEDでも、高値付近と安値付近では文脈が異なる。

### 2. 誰が積極的か

- BUYか
- SELLか
- 圧力比はどの程度か
- 継続率はどの程度か

### 3. 価格はどう答えたか

- 同方向へ進んだか
- 横ばいか
- 逆方向へ進んだか
- 高値または安値を更新したか
- 更新してから戻されたか

### 4. その後どうなったか

- 1分後
- 3分後
- 5分後
- 10分後

DeltaEngineは、この最後の項目を自動保存する。

---

## 3. 黄色を点ではなく過程として読む

BUY_STALLEDが1回出たとする。

```text
買い圧力 → 価格は横ばい
```

この時点で分かることは、買い圧力が価格を十分に押し上げられていないことだけ。

次の展開を観察する。

### 展開A: 黄色からEFFECTIVEへ

```text
買い停滞 → 売り流動性を食べ切る → 価格上昇
```

買い圧力が遅れて価格へ反映された可能性がある。

### 展開B: 黄色からUNCLEARへ

```text
買い停滞 → 買い圧力が弱まる → 明確な偏りが消える
```

一時的な偏りだった可能性がある。

### 展開C: 黄色から紫へ

```text
買い停滞 → 買いが続く → それでも上がらない → 価格下落
```

買い圧力が効かなかっただけでなく、価格が逆方向へ動き始めた。

第2講で最も注目するのは、この状態遷移である。

---

## 4. 紫を見たときの正しい考え方

BUY_TRAPPEDなら、積極買いが優勢なのに価格が下落している。

この状態から立てられる仮説:

- 買いを上回る売り流動性が存在した
- 積極買いが高い価格で捕まっている
- 価格を押し上げる力が見た目のDeltaほど強くない

この状態から断定できないこと:

- 必ずさらに下がる
- 捕まった参加者が必ず損切りする
- 大口が売っている
- 天井が確定した

紫は異常の発見であり、未来の保証ではない。

---

## 5. 時間窓を「倍率」として考える

DeltaEngineは次の窓を同時に監視する。

```text
30秒 / 1分 / 3分 / 5分 / 15分 / 30分
```

これは6人の別々の予測者ではない。

同じ相場を6種類の倍率で見ている。

### 30秒

変化へ最も早く気づく。

### 1分

30秒の現象が、少し長く続いているか確認する。

### 3分・5分

短いノイズではなく、構造として広がっているか確認する。

### 15分・30分

短期現象が、より大きな背景の中でどう位置づけられるかを見る。

### 誤った数え方

```text
30秒で紫 = 売り1票
1分で紫  = 売り1票
3分で紫  = 売り1票
合計3票なので強い売り
```

これは誤り。

同じ約定群が30秒、1分、3分の窓へ重複して含まれている。

### 正しい読み方

```text
30秒で異常が発生
→ 1分でも解消しない
→ 3分の構造へ広がった
```

投票数ではなく、現象の持続時間として読む。

## 6. 実例1 — 買い停滞から買い逆行へ

データ: BTCUSDT、2026-07-21 16:20前後（日本時間）

これはDeltaEngineが生まれた目的に非常に近い実例である。

### 状態の始まり

16:20:14、30秒窓でBUY_STALLEDが記録された。

| 項目 | 値 |
|---|---:|
| 観測価格 | 65,960.0 |
| 買い圧力比 | +60.6% |
| 方向継続率 | 73.3% |
| 観測中の価格変化 | +0.03bps |
| 約定数 | 2,640 |

買い圧力比は非常に大きい。

しかし価格変化は+0.03bpsで、ほぼ動いていない。

これは典型的な「大量の積極買いに対して価格が答えていない」状態。

### 1分窓へ広がる

2秒後の16:20:16、1分窓でもBUY_STALLEDが記録された。

| 項目 | 値 |
|---|---:|
| 観測価格 | 65,960.0 |
| 買い圧力比 | +55.9% |
| 方向継続率 | 71.7% |
| 観測中の価格変化 | +0.92bps |
| 約定数 | 3,211 |

30秒だけの一瞬の現象ではなく、1分窓でも買い圧力が価格を押し上げられていない。

### 停滞が継続

16:20:29、30秒窓と1分窓の両方でBUY_STALLEDとなった。

| 時間窓 | 買い圧力比 | 継続率 | 価格変化 | 約定数 |
|---|---:|---:|---:|---:|
| 30秒 | +52.5% | 66.7% | +0.02bps | 3,082 |
| 1分 | +42.5% | 73.3% | +0.73bps | 3,634 |

ここまでの観測事実:

- 買い圧力は一貫して明確
- 30秒だけでなく1分でも継続
- 数千件の約定を伴っている
- それでも価格はほぼ前進していない

### 黄色から紫へ

16:20:34、30秒窓がBUY_TRAPPEDへ変化した。

| 項目 | 値 |
|---|---:|
| 観測価格 | 65,951.0 |
| 買い圧力比 | +49.3% |
| 継続率 | 60.0% |
| 価格変化 | -1.32bps |
| 約定数 | 3,244 |

買い優勢が続いているのに、価格が逆方向へ下がり始めた。

その後、1分窓もBUY_TRAPPEDへ変化した。

| 時刻 | 時間窓 | 買い圧力比 | 継続率 | 価格変化 |
|---|---:|---:|---:|---:|
| 16:20:41 | 1分 | +38.2% | 63.3% | -1.47bps |
| 16:20:45 | 1分 | +44.0% | 60.0% | -2.38bps |

### 3分窓にも現れる

16:20:48、3分窓でBUY_STALLEDが記録された。

| 項目 | 値 |
|---|---:|
| 観測価格 | 65,936.0 |
| 買い圧力比 | +31.2% |
| 継続率 | 61.5% |
| 価格変化 | +0.93bps |
| 約定数 | 6,885 |

短期の買い不発が、3分窓でも確認できる状態へ広がった。

### その後の実測

16:20:29のBUY_STALLEDを基準にした事後成績:

| 経過時間 | 価格 | リターン |
|---|---:|---:|
| 発生時 | 65,959.8 | 0 |
| 1分後 | 65,893.4 | -10.07bps |
| 3分後 | 65,905.2 | -8.28bps |
| 5分後 | 65,873.5 | -13.08bps |

16:20:34のBUY_TRAPPEDを基準にした事後成績:

| 経過時間 | 価格 | リターン |
|---|---:|---:|
| 発生時 | 65,951.0 | 0 |
| 1分後 | 65,893.4 | -8.73bps |
| 3分後 | 65,899.9 | -7.75bps |
| 5分後 | 65,873.5 | -11.75bps |

### この実例から言えること

- 強い買い圧力が価格を押し上げられなかった
- 停滞が30秒から1分へ持続した
- その後、買い圧力と価格が逆方向になった
- 今回は、その後1〜5分で価格が下落した

### この実例だけでは言えないこと

- BUY_STALLEDなら常に下落する
- BUY_TRAPPEDなら必ず売ればよい
- 何bpsの下落が常に期待できる
- この1件だけで統計的優位性が証明された

この実例は仮説を支持する1標本であり、法則の証明ではない。

## 7. 実例1の時系列を一行で読む

```text
16:20:14  30秒: 買い停滞（黄色）
16:20:16   1分: 買い停滞（黄色）
16:20:29 30秒/1分: 停滞継続
16:20:34  30秒: 買い逆行（紫）
16:20:41   1分: 買い逆行（紫）
16:20:48   3分: 買い不発が長い窓にも広がる
その後1〜5分: 約7〜13bps下落
```

色を点で見ると、黄色や紫が何度も出ただけに見える。

時間の流れで見ると、

> **買い圧力が価格を動かせず、停滞が持続し、短期窓から逆行へ変わり、長い窓へ広がった**

という一つの物語になる。

## 8. 実例2 — 売り逆行は一度上昇したが、その後戻った

データ: BTCUSDT、2026-07-21 16:16前後（日本時間）

この実例は、紫が永続的な未来予測ではないことを教えてくれる。

### 売り停滞

16:15:51、30秒窓でSELL_STALLED。

| 項目 | 値 |
|---|---:|
| 観測価格 | 65,883.4 |
| 売り圧力比 | -26.7% |
| 継続率 | 60.0% |
| 価格変化 | -0.53bps |
| 約定数 | 785 |

売り優勢だが、価格はほとんど下がっていない。

### 売り逆行

16:16:22、30秒窓と1分窓でSELL_TRAPPED。

| 時間窓 | 売り圧力比 | 継続率 | 価格変化 | 約定数 |
|---|---:|---:|---:|---:|
| 30秒 | -31.5% | 62.1% | +2.67bps | 621 |
| 1分 | -29.5% | 61.0% | +1.27bps | 1,486 |

積極売りが優勢なのに価格が上昇している。

### その後の実測

16:16:22のSELL_TRAPPEDを基準にした事後成績:

| 経過時間 | 価格 | リターン |
|---|---:|---:|
| 発生時 | 65,895.4 | 0 |
| 1分後 | 65,899.9 | +0.68bps |
| 3分後 | 65,955.0 | +9.04bps |
| 5分後 | 65,888.0 | -1.12bps |
| 10分後 | 65,893.9 | -0.23bps |

### この実例が教えること

3分後だけ見れば、売り圧力に逆らって価格が上昇し、SELL_TRAPPEDの仮説と整合する。

しかし5分後には発生価格を下回り、10分後にはほぼ発生価格へ戻っている。

つまり、

> **ある観測が有効でも、その効果が何分続くかは別問題である。**

1分、3分、5分、10分を分けて保存する理由がここにある。

## 9. 「方向」と「寿命」を分ける

状態研究では二つの質問を分ける。

### 質問A: どちらへ動きやすかったか

例:

```text
BUY_TRAPPEDのあと、下落したか
SELL_TRAPPEDのあと、上昇したか
```

### 質問B: その効果は何分続いたか

例:

```text
1分後だけ有効だったか
3分後に最大化したか
5分後には消えたか
10分後に反転したか
```

実例2では、売り逆行後の上昇は3分時点で大きかったが、5〜10分では消えている。

したがって「方向が合った」という結果だけでは、実用ルールにならない。

## 10. チャート観察の実践手順

### 段階1: 発見

30秒または1分で黄色・紫を見つける。

記録するもの:

- 時刻
- BUYまたはSELL
- STALLEDまたはTRAPPED
- 圧力比
- 継続率
- 価格変化bps

### 段階2: 持続確認

次の窓へ広がるか確認する。

```text
30秒 → 1分 → 3分
```

ただし、票数として数えない。

### 段階3: 状態遷移確認

色がどう変化するかを見る。

```text
STALLED → TRAPPED
STALLED → EFFECTIVE
TRAPPED → UNCLEAR
TRAPPED → EFFECTIVE
```

### 段階4: 事後確認

1分、3分、5分、10分後を確認する。

### 段階5: 結論を急がない

最低でも複数日、異なる時間帯、異なる値動き環境で標本を集める。

## 11. 観測事実と解釈を分ける練習

### 悪い記録

```text
大口が買いを吸収した。もうすぐ暴落する。
```

問題点:

- 大口の存在を確認していない
- 意図を断定している
- 未来を確定している

### 良い記録

```text
1分窓で買い圧力+42.5%、継続率73.3%、価格変化+0.73bps。
BUY_STALLEDの13秒後、30秒窓がBUY_TRAPPEDへ変化。
1分後リターン-10.07bps、3分後-8.28bps、5分後-13.08bps。
```

良い記録は、あとから別の人が同じデータを確認できる。

## 12. 初期データを研究するときの注意

### 標本数が少ない

現在は稼働初日のデータ。

実例は見つかったが、勝率や期待値を結論づける段階ではない。

### 同じ現象の重複

数秒ごとの状態変化や複数時間窓が、同じ相場現象から発生することがある。

イベント件数をそのまま独立標本数と考えない。

### 相対出来高が未算出の場合

相対出来高は30分基準を必要とする。

開始直後の`None`は出来高ゼロではなく、基準未完成を意味する。

### 最大上下幅の初期データ品質

2026-07-21の初期データ確認で、価格0・数量0の保存行が混入していることを確認した。

抽出時点の確認結果:

- 価格0かつ数量0の行: 1,557件
- 保存イベント82件中、端点価格0を含むイベント: 6件
- その影響で一部の`max_down_bps`が`-10000`になっている

原因は、約定正規化が非正値を許し、価格0の基準値が事後追跡へ登録されたことだった。
約60秒後のリターン計算でゼロ除算が起き、ライブパイプラインも停止していた。

この問題は2026-07-21に修正済みである。

- 正規化、Flow検出、事後追跡の3層で非正値・非有限値を拒否
- 修正後のライブ運転開始: 2026-07-21 18:30:41 JST
- 再起動後に保存された2,732行中、価格または数量が0以下の行: 0件
- 1分を超えるライブ確認後も`/api/health`はGREEN、例外数0
- 対象テスト46件、全体テスト320件が合格

修正前のデータは監査証跡として削除しない。ただし、次を研究値として使わない。

- `max_down_bps`
- `max_up_bps`のうち異常価格を含む可能性があるもの
- `first_price <= 0`
- `last_price <= 0`
- `abs(price_change_bps) > 100`となる異常イベント

修正後の境界以降をクリーンな主標本とする。
修正前データを使う場合、この講義の実例と同様に、観測価格と事後価格がどちらも正の値で、
価格変化が正常範囲にある行だけを使用した。

この注意は、大作の価値を否定するものではない。
研究道具では「どのデータを信用してよいか」を明示すること自体が重要である。

## 13. 今日の観察課題

黄色または紫を一つ見つけたら、次を記録する。

```text
発生時刻:
最初に色が出た時間窓:
圧力側: BUY / SELL
最初の状態: STALLED / TRAPPED
圧力比:
継続率:
価格変化bps:

30秒後の状態:
1分後の状態:
3分窓へ広がったか:

1分後リターン:
3分後リターン:
5分後リターン:
10分後リターン:

観測事実:
自分の仮説:
仮説と事実を混ぜていないか:
```

今日は売買判断を作らない。

まず、色が時間の中でどう変化するかを見る訓練をする。

---

## 14. 確認問題

### 問1

30秒、1分、3分でBUY_TRAPPEDが出た。なぜ売りシグナル3票と数えてはいけないか。

### 問2

BUY_STALLEDからBUY_TRAPPEDへ変化した。この時点で何が新しく分かったか。

### 問3

SELL_TRAPPEDの3分後に+9bps、10分後にほぼ0bpsだった。何を意味するか。

### 問4

相対出来高が`None`だった。出来高がなかったという意味か。

### 問5

実例1から「BUY_STALLEDは必ず下落する」と結論づけてよいか。

---

## 15. 解答

### 問1の答え

同じ約定群が複数の時間窓へ重複して含まれるため。独立した3標本ではなく、
一つの現象が異なる時間幅へ持続している可能性がある。

### 問2の答え

買い圧力が価格を押し上げられないだけでなく、価格が買い圧力と逆方向へ
動き始めたことが分かった。

### 問3の答え

売り逆行後の上昇効果は3分時点では大きかったが、5〜10分では消えた。
方向だけでなく効果の寿命を研究する必要がある。

### 問4の答え

違う。30分の基準出来高がまだ完成していなかった可能性がある。

### 問5の答え

結論づけてはいけない。仮説を支持する1標本を観測しただけであり、
異なる日・時間帯・相場環境で十分な標本が必要。

---

## 16. この講義で最も大切な一文

> **黄色や紫が出た瞬間ではなく、黄色が紫へ変わるのか、消えるのか、価格追随へ戻るのかを見る。**

DeltaEngineは色を当てる装置ではない。

圧力と価格反応の関係が、時間の中でどう変化し、その後の値動きへどうつながったかを
保存し、検証する装置である。
