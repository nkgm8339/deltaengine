# ADR-011: 全量記録の原則 (No-Decimation Recording Principle)

**Status**: Accepted / **Date**: 2026-07-20
**Supersedes(部分)**: v3.6.0 の Order Book 永続化 out-of-scope 判断 (M11 raw not persisted) を原則レベルで見直す。ADR-008 は射程に含むが即時改廃せず対象拡張フェーズで再評価。

## Context
本プロジェクトの本質は、一個人が自らの手元で相場を分析し後から振り返って学ぶ道具を作ることにある。機関規模の容量問題は個人・単一銘柄規模には当てはまらない。オーナーの実務経験から三原則が示された。
一、順番通り全部見る。今関係あるか否かで項目を間引かない。関係なさそうな項目こそ見逃しの温床。
二、一寸先は分からない。当たり外れは後にならないと分からず「なぜあのときこれを見なかったのか」は避けられない。今この瞬間に後で効くかを判断して捨てることは原理的に不可能。
三、記録は経験の届かない守備範囲を埋める計器である。相場は世界が広すぎ経験だけでは覆えない。

## Decision
取得したデータをその場の関連性判断で間引かず、後から分析・再生できる形で全量記録することを原則とする。板・約定・ローソク足・清算・将来の全フィードに及ぶ。「間引かない」は三軸に効く。
軸1 時間: 後から見るため全量を残す。
軸2 表示: 表示層と蓄積層を分離。蓄積を特定の見せ方に従属させない。クラシックも新表示も同一蓄積を各流儀で読む下流に過ぎない。表示用の間引き蓄積を作ってはならない。
軸3 加工: 蓄積の土台は取引所からの生データの時系列保持。加工物は生からの派生でいつでも再計算できる。「生」とは取引所から届いたまだ整えていないメッセージそのものを最優先とする。正規化が捨てた情報は復元できず、何を捨てるか事前判断すること自体が「今の判断で間引く」ことに当たる。届いたものを判断せず丸ごと残す。
欠損の非隠蔽: 生でもデータ落ちは一定確率で起きる。これを隠蔽しない。生のまま保持すれば欠損は欠損として後から見える。欠損を隠した綺麗なデータより、欠損が見える生の方が後の分析で信頼できる。

## 実装方針(原則は広く、手は最短)
原則の射程は全データだが実装は段階的。Order Book 永続化から着手(欠落の痛みが最大かつ既に diff が流れている)。対象拡張は必要に応じ順次。全データを直ちに完璧に記録せよの意ではない。過剰な先回り実装(保身の作業)は禁止。

## Consequences
得るもの: 過去の任意局面を当時見えた情報とともに再生・検証でき答え合わせが可能。板依存分析(Absorption・板ヒートマップ)がリプレイで再現。将来どんな見せ方・指標も生に遡って再計算でき過去データも新表示で振り返れる。
コスト: ストレージ増(個人・単一銘柄では許容)。記録・再生ロジック追加。粒度(生べた書きか周期snapshot+diffか)はコード実物確認の上で別途決定。
不変: ライブ分析挙動(板はライブで完全機能、本ADRは保存可否のみ変更)。既存 Tick/Candle スキーマ(本ADRは追加であり削除・改変でない)。

## Notes
本ADRは思想(なぜ)を定める。記録形式・スキーマ・リプレイ配線(どう)は後続の実装指示書でコード実物確認を経て決定。ADR-000 の系譜に連なる根本思想の一枚。
