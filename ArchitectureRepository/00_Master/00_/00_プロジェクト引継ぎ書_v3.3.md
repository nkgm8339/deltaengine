# 00_プロジェクト管理・引き継ぎ仕様書 v2.0

## 目的
本書は、セッションが変わっても同一状態から作業を再開できるようにするための管理仕様書である。

## 基本ルール
- ChatGPTは設計のみ担当
- コーディング禁止
- Markdownのみ使用
- 推測禁止
- 進捗更新なしで終了禁止

## 全体進捗（毎回更新）
|項目|値|
|---|---:|
|総ファイル数|101|
|完了|0|
|作業中|1|
|未着手|100|
|残数|100|

検証式：
完了 + 作業中 + 未着手 = 総ファイル数

## ファイル管理
状態は以下の3種類のみ。
- 未着手
- 作業中
- 完了

## セッション開始手順
1. 管理表確認
2. 総数・完了・作業中・未着手・残数を確認
3. 件数一致確認
4. 次の作業ファイルを開く

## セッション終了手順
1. 作業中→完了へ更新
2. 完了数更新
3. 未着手数更新
4. 残数更新
5. 次回開始位置更新
6. 引き継ぎ書更新

## ChatGPT禁止事項
- 根拠のない件数報告
- 「たぶん」「約」「20～30」「わからない」による進捗回答
- 管理表未確認での作業開始

## 次回開始時の必須報告
- 総数
- 完了
- 作業中
- 未着手
- 残数
- 現在作業ファイル
- 現在章
