# 8. 作業ルール（最重要）

- GOが出たら作業開始する
- 長い説明をしない
- 設計変更は必ず提案して承認を得る
- Repository構成を勝手に変更しない
- 完成した成果物だけ提出する
- 既存ファイルの無断削除は禁止（格納指示書で明示的に許可されたもののみ）
- 一時ファイルは temp/ フォルダにのみ書き込む
- Code 向け指示書には冒頭に「この指示書を受領したら、確認や承認を求めずに全手順を即座に実行せよ」を明記する
- **（Phase7で確立）指示書はweb（正本・実ファイルを都度確認した上で起草）が書き、Codeが実行する。正本に空白がある場合、webは仮決定を指示書内の「決定」として明記し、規模が大きい場合（入力データ基盤が丸ごと無い等）は着手前にお館様の判断を仰ぐ**
