# 3. 主要な設計決定(要旨)

- **通信方式(ADR-002)**: パイプライン段間は `asyncio.Queue`(有界・オーバーフロー時はErrorCodes準拠)。Order Flow Engine 内の4計算器へは直接呼び出し
- **並行性(ADR-003)**: 単一プロセス asyncio イベントループ。重い処理は executor へ退避。可変状態の共有禁止
- **SignalEngine**: CVD・Footprint・Imbalance を −100〜+100 に正規化し加重合算。confidence = |composite|/100。Absorption は composite 方向への逆行検出時に WAIT へ強制(veto)
- **DataNormalizer**: 独立モジュール。取引所プロファイル(Config駆動)で差異吸収。重複破棄・reorder_tolerance(500ms)付き並べ替え
- **MT5Adapter**: プラットフォーム側がTCPサーバ、MQL5標準Socketで接続。改行区切りJSON。一方向配信(自動売買なしと整合)
