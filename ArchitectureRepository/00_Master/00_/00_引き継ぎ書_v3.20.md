# 2. 本セッションでやったこと

**ADR-011「全量記録の原則(No-Decimation Recording Principle)」を新規制定・配置(OK 確認済)。**

- 動機: 板を out-of-scope で捨てた v3.6.0/M11 判断を原則から見直す。「一寸先は分からない相場では、その場の判断でデータを間引くこと自体が危険。大元の生を全量残し後から分析する」
- 三軸で「間引かない」を定義: 時間(後から見るため全量)/表示(蓄積を見せ方に従属させない。クラシックも新表示も同一蓄積の下流)/加工(土台は取引所の生データ時系列。加工物は派生でいつでも再計算可)
- 生の定義: 取引所から届いた未整形メッセージそのものを最優先。正規化後は捨てた情報が復元不能なので次善
- 欠損の非隠蔽: 生のまま残せば欠損が欠損として見える
- 実装は段階的: Order Book 永続化から着手
- ファイル: `ADR-011_No_Decimation_Recording_v3.0.md`(Status: Accepted)
