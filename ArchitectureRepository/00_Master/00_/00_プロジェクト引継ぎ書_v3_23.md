# 3. 撤去する収束装置（実物確認済）

複数指標を1つの結論へ収束させる装置は、名前が違うだけで根は同じ `composite`。以下すべて撤去対象。

## 3.1 composite（根）

`signal.py evaluate` L204: `composite = Σ(wᵢ×scoreᵢ)/Σ(wᵢ)`。加重前スコアを足し合わせて1本にする本体。

## 3.2 market_state 枠

composite→signal/confidence の写像に過ぎない。撤去。

## 3.3 signal 枠（BUY/SELL/WAIT）

composite の符号を direction（+1/-1/0）にして1語に丸める枠（evaluate L207-213, L254-260）。数字を丸めない方針に正面から反する。撤去。

## 3.4 confluence

`push_broker.confluence()`（L150-190）。composite に依存している。
- WAIT 時は composite の符号を direction のフォールバックに使う（L168-176）。composite がゼロ/不在なら全フラグ False で返す。
- 各指標の一致フラグは「composite 投入と同じ score」を「composite が決めた方向」で照合。
- **composite を撤去すると土台ごと成立しない。** 配線ごと撤去。

## 3.5 absorption veto ← 撤去する。残さない。

`signal.py evaluate` step 5（L236-246）。
- veto の against 判定（L241-244）は `direction`（=composite の符号）に逆らう吸収かどうかで立つ。**composite 依存。**
- 依存以前の問題として、**veto はある指標のきっかけで別の結論を打ち消す＝指標をぶつけて収束させる装置そのもの**。composite と同じ穴。芯に反するので残さない。
- absorption は veto という役から完全に外す。**吸収が出たというきっかけを classification（BUY吸収/SELL吸収の別）と strength の数字のまま、独立所見として出すだけ**にする。何かを打ち消す役には二度と就けない。

# 5. 5指標の独立所見（数字を丸めない）

俯瞰指標。0.01の単発成り行きは指標にしない。積み重なった結果の地形と、その地形が変わった瞬間（きっかけ）を見る。

| 指標 | 何を指標にするか | 常時/事件 |
|---|---|---|
| CVD | 累積 cvd の傾き（バー単体デルタでない） | 常時 |
| Footprint | POC / VA（他指標が起きる舞台） | 常時 |
| Imbalance | Stacked の段数(count)と価格帯（壁の厚みと場所） | 事件（積み上がり時のみ） |
| Absorption | classification と strength と発生価格（丸めない） | 事件（発火時のみ） |
| Flow | 5イベント(sweep/exhaustion/large/unfinished/tape)を平均せず個別に、強さと側 | 事件（発火時のみ） |

**見せ方2種**: 常時もの（CVD傾き・Footprint）は数字を出しっぱなし。事件もの（Imbalance壁・Absorption・Flow）は発火時だけ出し、非発火は沈黙。飾りで点灯させない。
