# 2. 本セッションで確定した設計思想の転換

- **合成スコアを廃止する。** SignalEngine の `composite = Σ(wᵢ×scoreᵢ)/Σ(wᵢ)` は撤去対象。CVD・Footprint・Imbalance・Flow は各々独立した一人前の指標であり、重み付け・共通スケール・指標間の共通契約はすべて捨てる。指標同士を足さない・混ぜない・揃えない。
- **market_state 枠を廃止する。** `analysis.py` の market_state は signal/confidence の写像に過ぎず、合成廃止で存在意義がゼロ。UI 上の枠は撤去し、そこへ CVD Area を置く（後で移動可）。

# 3. CVD の確定仕様（足場）

CVD は単独で以下3つの読みを吐く。他指標と統合しない。

1. **方向（常時表示）**: BULL / BEAR / NEUTRAL。傾きは固定 `cvd_slope_ref` を廃止し、自己正規化で状態化する。候補は「デルタ比率 = bar_delta / bar_volume（構造的に[-1,+1]）」または「ローリング z スコア」。
2. **ダイバージェンス（発火時のみ）**: 価格 × CVD の食い違い。`divergence.py`（MOD-012、BULLISH/BEARISH 実装済）を shadow から配信・表示へ昇格させる。
3. **吸収文脈（発火時のみ）**: CVD が動くのに価格が動かない。既存 Absorption 検出と重なる領域。

**鉄則**: 方向は常時、ダイバージェンス・吸収は検出器が実際に発火したときだけ表示する。非発火時は沈黙させる。飾りで点灯させない。

---

# 3.5 独立化対象（フッカー候補・CVD 以外も全て）

**本件は CVD 限定ではない。** 合成に潰されていた全指標を、各々独立した所見を吐くよう作り直す。CVD は最初の足場に過ぎず、以下も同じ扱いで候補に入れる。各指標の「常時の読み」と「発火時のみの読み」を個別に定義し、指標間で足さない・混ぜない・揃えない。

| 指標 | 現状 | 独立所見（要定義） |
|---|---|---|
| CVD | 足場確定（§3） | 方向 / ダイバージェンス / 吸収文脈 |
| Footprint | 昇順契約・VA/POC は webapp 表示のみ | 買い売り優勢 / インバランス位置 / VA・POC |
| Imbalance | Ratio / Stacked 実装済、composite に投入 | Stacked 発火 / 対角比率 / 方向 |
| Flow | 5検出器（Large/Sweep/Exhaustion/Unfinished/Tape） | 各イベントの発火（現状 score 平均で潰している） |
| Absorption | 検出器稼働、現状 veto のみ | 吸収イベント（分類 + strength）を独立所見として表出 |

※ 各指標の native 所見の確定と、合成撤去後の pipeline 切り分けは、実物確認のうえで指標ごとに行う。一括変換で他を壊さないこと。
