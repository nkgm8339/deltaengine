# 指示書_退避線構築_v1

**対象**: DeltaEngine 全体（`C:\Users\user\Desktop\DeltaEngine`）
**目的**: オーダーブック再設計に着手する前に、後戻り不能な状態を構造的に不可能にする退避線を張る
**性質**: 本指示書の全操作は「追加のみ」である。既存ファイルの変更・削除・移動を一切含まない
**所要**: 数分。コード変更は含まない

---

## 0. 背景（実行者向け説明）

現在 `Delta_Engine_Pro4web/` は git 未追跡（untracked）である。つまり現行コードには git 上の戻し先が存在しない。この状態で reset / clean 系のコマンドを実行すると現行コードは物理消滅し復元不能になる。よって以下の順序を厳守すること。**第1層（物理コピー）を必ず最初に実行し、成功を確認してから第2層に進む。**

---

## 1. 第1層: git外の物理バックアップ（最優先）

```bat
xcopy /E /I /H /Y "C:\Users\user\Desktop\DeltaEngine" "C:\Users\user\Desktop\DeltaEngine_BACKUP_20260719"
```

完了検証（両方実行し、結果を報告に含めること）:

```bat
dir /s /a "C:\Users\user\Desktop\DeltaEngine" | findstr "個のファイル"
dir /s /a "C:\Users\user\Desktop\DeltaEngine_BACKUP_20260719" | findstr "個のファイル"
```

ファイル数が同等（コピー中に生成された一時ファイル分の±数件は許容）であることを確認する。大きく乖離していれば**ここで停止し報告**。第2層に進んではならない。

---

## 2. 第2層: スナップショットコミット + タグ

第1層の成功確認後にのみ実行する。

```bat
cd /d C:\Users\user\Desktop\DeltaEngine
git add -A
git commit -m "snapshot: full tree before orderbook redesign (v3.6.4 state)"
git tag SAFE-20260719
```

完了検証:

```bat
git status --porcelain
git log --oneline -1
git tag -l SAFE-20260719
git ls-files Delta_Engine_Pro4web/ | find /c /v ""
```

期待結果:
- `git status --porcelain` の出力が空（全ファイルがコミット済み）
- 最新コミットが上記メッセージ
- タグ `SAFE-20260719` が存在
- `Delta_Engine_Pro4web/` 配下のファイルが git 管理下に入っている（カウントが 0 でない）

注意: `.gitignore` により除外されるファイル（`__pycache__` / data / 実行時生成物）はコミットされなくてよい。ソース・設定・ドキュメント・webapp/static が入っていることを重視する。心配な場合は `git status --ignored -s | findstr /v "pycache data"` で、無視されている中に重要ファイルがないか目視確認し、あれば `git add -f` で追加してから commit する。

## 4. 禁止コマンド（本指示書の全工程完了まで、および今後も原則）

以下は理由の如何を問わず実行禁止。必要と判断した場合も実行せず停止して報告すること。

- `git clean -fd`（未追跡ファイルの物理全削除）
- `git checkout .` / `git checkout -- <path>`（未コミット変更の破棄）
- `git reset --hard`
- `git stash -u` / `git stash --include-untracked`
- `rmdir` / `del` / `Remove-Item` による DeltaEngine 配下の削除全般
