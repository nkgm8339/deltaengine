# 3. 5指標の定義（数字を丸めない）

俯瞰指標。0.01の単発成り行きは指標にしない。積み重なった結果の地形と、地形が変わった瞬間（きっかけ）を数字で出す。

## 3.1 一覧

| 指標 | 出す数字（丸めない） | 常時/事件 |
|---|---|---|
| CVD | 累積 cvd の傾き（バー単体デルタでない） | 常時 |
| Footprint | POC / VA（他指標が起きる舞台） | 常時 |
| Imbalance | Stacked の段数(count)と価格帯（壁の厚みと場所） | 事件（積み上がり時のみ） |
| Absorption | classification（BUY吸収/SELL吸収）と strength と発生価格 | 事件（発火時のみ） |
| Flow | 5イベント(large/sweep/exhaustion/unfinished/tape)を平均せず個別に、強さと側 | 事件（発火時のみ） |

## 3.2 常時ものと事件ものの扱い

- **常時もの（CVD傾き・Footprint）**: 数字を出しっぱなし。
- **事件もの（Imbalance壁・Absorption・Flow）**: 発火時だけ出す。非発火は沈黙。飾りで点灯させない。

## 3.3 丸めない鉄則（全指標共通）

- 方向（BUY/SELL/WAIT）に畳まない。
- 段階（STRONG/弱/中の3値等）に畳まない。
- 指標間で共通スケールに揃えない。各指標の native 単位のまま出す。

# 4. 撤去する収束装置（実物確認済）

複数指標を1結論へ収束させる装置は、名前が違うだけで根は同じ `composite`。全撤去。

## 4.1 composite（根）

`signal.py evaluate` L204: `composite = Σ(wᵢ×scoreᵢ)/Σ(wᵢ)`。

## 4.2 market_state

`src/ai/analysis.py` `AnalysisEngine.evaluate`（L64-101）。signal/confidence を STRONG_BULL〜STRONG_BEAR に写像するだけの下流。summary・risk_level も同じ写像系。撤去。

## 4.3 signal 枠（BUY/SELL/WAIT）

composite の符号を direction（+1/-1/0）にして1語に丸める（evaluate L207-213, L254-260）。撤去。

## 4.4 confluence

`push_broker.confluence()`（L150-190）。composite 依存（WAIT時に composite 符号をフォールバック、L168-176）。composite 撤去で土台ごと成立せず。配線ごと撤去。

## 4.5 absorption veto ← 撤去する。残さない。

`signal.py evaluate` step 5（L236-246）。against 判定が direction（=composite 符号）依存。かつ veto は「ある指標のきっかけで別の結論を打ち消す」収束装置そのもの。芯に反する。absorption は veto から完全に外し、classification と strength の数字のまま独立所見として出すだけにする。

# 5. 撤去の波及先（実物の地形・要承認）

§4 を落とすと以下に連鎖する。**先走って触らない。撤去範囲は本書で確定してから実装する。**

| 波及先 | 実物箇所 | 内容 |
|---|---|---|
| market_state 写像 | `ai/analysis.py` L64-101 | signal/confidence→市場状態。撤去対象 |
| market_state 消費 | `mt5/adapter.py` L252 / `push_broker.py` L256 | 配信・MT5送出が market_state を読む |

# 6. 撤去範囲の確定（本書で答える論点）

**論点**: 撤去を signal.py + push_broker confluence + veto に絞るか、§5 の波及先（analysis.py market_state / mt5 / storage / on_analysis payload）まで一括で射程に入れるか。

**方針（提案・お館様確定待ち）**: 収束装置は根が1つ（composite）なので、部分撤去は「composite を消したのに market_state 写像だけ生き残る」等の宙吊りを生む。**§4+§5 を一括射程**とし、保存スキーマ（storage）のみ、旧 signal 列を残すか捨てるかを別途1点だけ判断する。UI 契約（on_analysis payload）は5指標の独立所見を載せる新契約へ差し替える。

# 8. 材料の裏取り（実装可能性の確認）

- 累積 cvd は既に Candle に載っている。`cvd.py` `_BarAccumulator` が `delta`（バー単体・毎バーリセット）と `cvd`（バー最終約定時点の累積）を両方保持し `to_candle()` で渡す。**累積 cvd の傾きは新規計算器を足さず確定 Candle の `cvd` 系列から取れる。**
- 傾きの取り方（差分か回帰か・窓バー数）は決め打ちせず、両方式を実装し歯車で切替。窓も設定値。

# 9. 実装順序（本書承認後）

1. **CVD 1本目**: `pipeline.py` L530 `score_cvd(candle.delta, cvd_slope_ref)`（バー単体を固定基準で±100 clamp）を外し、累積 cvd の傾きを数字のまま出す経路へ。歯車ポップアップ同梱。この作業に §4 の収束装置撤去（+§6 で確定した範囲）を含める。
2. CVD で「指標＋歯車ポップアップ」の型を固める。
3. 残り4指標（Footprint / Imbalance / Absorption / Flow）を同じ型で横に並べる。各指標1つずつ native 所見を定義・表出。
