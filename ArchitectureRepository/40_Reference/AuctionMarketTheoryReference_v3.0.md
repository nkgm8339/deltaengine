# AuctionMarketTheoryReference_v3.0

# Purpose

Defines the canonical Auction Market Theory (AMT) terminology used
across the Order Flow Analysis Platform.

------------------------------------------------------------------------

## Core Concepts

  -----------------------------------------------------------------------
  Term                                Definition
  ----------------------------------- -----------------------------------
  Auction Market Theory               Framework describing price
                                      discovery through continuous
                                      auctions between buyers and
                                      sellers.

  Balance                             Market state where price is
                                      accepted within a defined value
                                      area.

  Imbalance                           Market state where one side
                                      dominates, causing directional
                                      movement.

  Price Acceptance                    Sustained trading activity at a
                                      price level.

  Price Rejection                     Failure of price to attract
                                      continued trading activity.

  Discovery                           Process of establishing a new fair
                                      value outside the prior balance.
  -----------------------------------------------------------------------

------------------------------------------------------------------------

## Reference Rules

-   This document is the SSOT for Auction Market Theory terminology.
-   Requirements, Architecture, and Modules shall reference these
    definitions.
-   Strategy-specific interpretations may extend but shall not redefine
    these concepts.
