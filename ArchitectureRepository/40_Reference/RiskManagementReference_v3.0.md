# RiskManagementReference_v3.0

# Purpose

Defines the canonical risk management terminology used throughout the
Order Flow Analysis Platform.

------------------------------------------------------------------------

## Core Concepts

  -----------------------------------------------------------------------
  Term                                Definition
  ----------------------------------- -----------------------------------
  Risk per Trade                      Maximum acceptable loss for a
                                      single trade.

  Position Size                       Quantity determined by predefined
                                      risk parameters.

  Stop Loss                           Protective exit limiting downside
                                      risk.

  Take Profit                         Target exit to realize gains.

  Risk/Reward Ratio                   Expected reward divided by accepted
                                      risk.

  Maximum Drawdown                    Largest peak-to-trough equity
                                      decline.

  Daily Loss Limit                    Maximum allowable cumulative loss
                                      in one trading day.
  -----------------------------------------------------------------------

------------------------------------------------------------------------

## Reference Rules

-   This document is the SSOT for risk management terminology.
-   Architecture, Requirements, and Modules shall reference these
    definitions.
-   Strategy-specific parameters shall extend but not redefine these
    concepts.
