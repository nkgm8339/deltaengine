# VolumeProfileReference_v3.0

# Purpose

Defines the canonical terminology for Volume Profile used throughout the
Order Flow Analysis Platform.

------------------------------------------------------------------------

## Volume Profile Elements

  -----------------------------------------------------------------------
  Term                                Definition
  ----------------------------------- -----------------------------------
  Volume Profile                      Distribution of traded volume
                                      across price levels.

  POC (Point of Control)              Price level with the highest traded
                                      volume.

  VAH (Value Area High)               Upper boundary of the value area.

  VAL (Value Area Low)                Lower boundary of the value area.

  Value Area                          Price range containing the
                                      configured percentage of traded
                                      volume.

  HVN                                 High Volume Node indicating
                                      acceptance.

  LVN                                 Low Volume Node indicating
                                      rejection.
  -----------------------------------------------------------------------

------------------------------------------------------------------------

## Reference Rules

-   This document is the SSOT for Volume Profile terminology.
-   Strategy and module documents shall reference these definitions.
-   Platform-specific rendering options are implementation details.
